# Linux Home Lab

A collection of hands-on Linux home lab projects focused on Ubuntu Server, Linux system administration, command-line operations, networking, security, user management, automation, and IT troubleshooting.

This repository documents my continued development of practical Linux administration and IT support skills through a virtualized Linux server environment.

## About

I built this Linux home lab to gain hands-on experience with Linux operating systems and administrative tasks commonly encountered in IT support and system administration environments.

Using Ubuntu Server and Oracle VirtualBox, I have started building a Linux environment to practice server installation, system configuration, command-line administration, networking, and troubleshooting.

As I continue expanding this environment, I plan to explore Linux file management, user and group administration, file permissions, SSH remote access, system services, Bash scripting, and automation.

Each lab includes step-by-step documentation, screenshots, challenges encountered, troubleshooting performed, and key concepts learned.

## Lab Environment

- **Hypervisor / Virtualization:** Oracle VirtualBox
- **Server Operating System:** Ubuntu Server 26.04.1 LTS
- **Server Hostname:** `ubu-srv-01`
- **Administrator Account:** `labadmin`
- **Network Configuration:** NAT (Network Address Translation)
- **Remote Administration:** OpenSSH Server
- **Command-Line & Administration Tools:** Linux Terminal, Bash, APT, `sudo`, `hostname`, `ip`, `ping`

## Lab Projects

### Lab 01 – Ubuntu Server Installation and Initial Configuration

- Downloaded and installed Ubuntu Server 26.04.1 LTS in Oracle VirtualBox, manually configuring the virtual machine, storage, operating system, and administrator account.
- Configured NAT networking to provide internet connectivity for software installation, package updates, and access to Ubuntu repositories.
- Installed OpenSSH Server to prepare the environment for future remote administration exercises.
- Verified the Ubuntu Server installation through the command-line interface and performed system package updates using APT.
- Created a VirtualBox snapshot to establish a recovery point before beginning future Linux administration labs.
